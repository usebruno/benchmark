How it works

The Pipeline

From code push to trend chart in four steps — fully automated.

01

Test

Playwright benchmarks run on Ubuntu, macOS, and Windows on every push to main.

02

Collect

Results are uploaded as GitHub Actions artifacts with full statistical summaries.

03

Ingest

Given a repo and commit SHA, the script finds the run, downloads artifacts, and discovers suites.

04

Visualize

This dashboard reads the JSON and renders trend charts. No build step — pure static HTML.

Schema

Data format

Two file types power the dashboard. Both are auto-managed by the ingestion script.

manifest.json

Registry of benchmark suites. Auto-populated when new suites are ingested.

{
  "suites": [{
    "id": "mounting",
    "name": "Collection Mount",
    "os": ["ubuntu", "macos", "windows"]
  }]
}

data/{suite}/{os}.json

Time-series array. One entry appended per CI run.

[{
  "commit": "abc1234",
  "date": "2026-05-06T12:00:00Z",
  "entries": {
    "bru-50": {
      "mean": 1428, "median": 671,
      "p90": 2507, "p99": 3044,
      "stdDev": 1088, "min": 626,
      "max": 3044, "count": 3,
      "timings": [3044, 626, 629]
    }
  }
}]
Extend

Add a new benchmark

Three steps. No manual config on the dashboard side.

1

Write the test

Create tests/benchmarks/{name}/{name}.bench.ts in the Bruno repo. Use writeResults() to output results.

2

Run it

Push to main or trigger manually. The ingestion script auto-registers the suite and creates data files.

3

Done

The dashboard picks it up on the next page load. Rename the suite in manifest.json if the id isn't readable.

Auto-registration: The ingestion script adds new suites and OS entries to manifest.json automatically. Suite ids come from the results filename — results/mounting.json becomes suite mounting.
CI

Ingestion

Two inputs. Zero config. The script discovers everything from the GitHub API.

Automatic

Bruno CI sends a repository_dispatch with the repo and commit SHA. The script finds the run, downloads artifacts, and discovers suites and OS from filenames.

Manual

Go to Actions → Ingest Benchmark Results → Run workflow. Provide the source repo and commit SHA. That's it.

How discovery works: The script calls the GitHub API to find the Benchmarks run for the commit, lists benchmark-results-* artifacts to determine OS, and scans results/*.json inside each artifact for suite ids.
